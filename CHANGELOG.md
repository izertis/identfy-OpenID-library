# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## 0.2.0 - 2024-04-30
- General Refactor
- Added the "State Manager" class to enable interaction with an abstract data storage for managing the state of requests.
- Added new methods to allow direct generation of authorization requests.
- Simplified the library by removing callbacks.
